This application uses Node.js, Express, EJS, Bootstrap, and SQLite to create a bakery inventory website. 
The project uses separation of concerns by keeping the routes in app.js, database functions in database.js, and the user interface in the views folder. 
Product images and CSS are stored in the public folder.
The application uses routes for Products, About, and Contact. These routes are connected via the navigation menu so users can move between the pages. The Products page retrieves the bakery products from the database and displays them using Bootstrap cards.
